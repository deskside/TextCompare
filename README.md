# 👀 新旧手册对比，看清变化

给两版手册找不同，就像给修订内容打上聚光灯：旧版删了什么、新版加了什么，一眼看清。

## 三步开工

1. **放入文字**：左边粘贴旧版，右边粘贴新版。也可以从 WPS 复制 **1行×2列** 的表格，点击下方粘贴区，按 **Ctrl+V**，两版文字自动各就各位。
2. **点亮变化**：点击“对比并标色”。删除穿红衣，新增穿蓝衣，没变的保持黑色；变化所在的显示行也会亮起淡色背景。增删字数一起报到，还有一小束烟花庆祝完工。
3. **带走结果**：分别复制旧版、新版文字，或者一键复制无边框的两列表格。在 WPS 文字中选择**保留源格式**，修订颜色跟着走，文字统一为**黑体、10磅**。

想留一份对照稿？点击“导出 PDF”，在打印窗口选择“另存为 PDF”。A4横向左右对照，长内容自动分页，每页带标题和页码，文字可以选择、搜索。

## 使用小贴士

- 标点、空格和换行不参加“找不同”，也不计入增删字数；汉字、英文字母和数字各算1字。
- 相同内容整行、整段搬家，仍保持黑色；段内局部移动暂未完整支持。
- 网页里的行高亮像便签，只在页面和 PDF 中亮相，复制到 WPS 时不会带走。
- 修改输入后，请重新对比，让结果跟上最新版本。

## 打开就用

用浏览器打开 `index.html`，并让它和 `pdf-export.js` 待在同一文件夹。不用安装，文字在本地处理，不会上传服务器。

PDF 建议使用 A4横向、无边距，关闭浏览器页眉页脚；若高亮没有出现，请开启“背景图形”。
